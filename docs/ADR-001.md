# ADR 001 · Management UI stack

Status: selected for the V2 candidate, comparative implementation evidence incomplete.

The console has two documents, a small number of forms, a detail inspector and tables rendered from a bounded API. The selected candidate uses strict TypeScript, standard HTML controls and shared Graphite CSS. Its production JavaScript has zero package imports. TypeScript and Playwright are pinned build and test dependencies. A production installer carries the compiled assets inside the Admin executable.

| Candidate | Published reference | License | Integration and accessibility |
|---|---|---|---|
| shadcn/ui | CLI 4.x, registry supports Base UI and Radix | MIT | Local component source plus React, headless primitives and Tailwind. Good fit if several React tools share copy-owned components. [Official documentation](https://ui.shadcn.com/docs/official) |
| Base UI | 1.9.0 | MIT | React headless primitives; focus, keyboard and interaction support with local styling. [Releases](https://base-ui.com/react/overview/releases) |
| Radix Primitives | Individually released packages | MIT | React headless primitives with dialog and tooltip keyboard/focus APIs. [Releases](https://www.radix-ui.com/primitives/docs/overview/releases) |
| Mantine | 9.8.0 | MIT | React component library with rich patterns, theme tokens and required component CSS. [Releases](https://mantine.dev/changelog/all-releases/) |
| Ant Design | 6.7.2 | MIT | React table/forms and theming; suite behavior and CSS come with a larger integration surface. [Changelog](https://ant.design/changelog/) |
| daisyUI | 5.7.x | MIT | Tailwind classes, CSS themes and HTML semantics. Native or application-owned behavior for focus, dialogs and interactive table options. [Changelog](https://daisyui.com/docs/changelog/) |
| Headless UI | React 2.2.10 | MIT | React/Vue headless behavior with custom styling. [Releases](https://github.com/tailwindlabs/headlessui/releases) |

For the shipped candidate, the Playwright fixture exercises a high-density connections table, native modal focus, keyboard actions, responsive widths and the local-asset constraint. The dev workstation has locked compiler and browser packages available locally. The React/shadcn, TypeScript/daisyUI and React/Mantine full prototypes still require package availability and comparative builds. This ADR records no measured relative size or load-time claims for those three packages.
